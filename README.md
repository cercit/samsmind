# SamsMind, public notes

A read-only slice of my second brain: 47 notes I chose to share, shown as a map. Each dot is a note and lines join related notes. Hover to preview, click to read, or search.

Live: https://cercit.github.io/samsmind/

The app itself (capture, sorting, linking and Ask) runs on my laptop and is not public. Only notes I approved and marked shareable are here.
